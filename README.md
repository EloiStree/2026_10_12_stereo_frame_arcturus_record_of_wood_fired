# Wood-Fired Cooking Sample

> Recording of a wood-fired oven using Steam Frame Arcturus and QooCam Ego.

To provide the community with photos and videos from the Arcturus Steam Frame video, I recorded my father's wood-fired oven while helping my parents with the firewood.

Git is not the best platform for hosting videos, so this repository contains only a small sample of photos and videos that fit within the repository's size limits.
